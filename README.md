# Tariku Teshome — Graphic Designer Portfolio

This is a responsive, single-page portfolio website tailored to the Kemen Creative Graphic Designer vacancy.

## Important before applying
The four project cards are intentionally presented as concept/case-study categories. Replace them with your REAL design work/screenshots before sending the portfolio to an employer. Do not claim concept work as client work.

## Files
- index.html — complete portfolio website
- README.md — instructions

## How to use
1. Open `index.html` in Chrome to preview it.
2. Replace the project concept visuals with your real work if desired.
3. Update your email/phone/social links if needed.
4. Upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting service.

## Job targeting
The portfolio emphasizes:
- Adobe Photoshop
- Adobe Illustrator
- Branding
- Typography
- Color and layout
- Social media design
- Posters and promotional design
- Professional communication and process
